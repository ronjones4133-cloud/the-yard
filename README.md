# The Yard

**The world is out there. The good stuff comes home.**

The Yard is a personal collection of tools for
remembering great food, memorable pours,
favorite restaurants, and experiences worth keeping.

## Collections

- The Port Cellar — Port discovery and tasting journal
- Dining Journal — Restaurant visits and favorite dishes
- Bourbon Bench — Bourbon tasting notes
- From the Grill — Recipes and outdoor cooking
- Notes from the Yard — Experiences and memories

## Technology

- HTML
- CSS
- JavaScript
- GitHub Pages
- Browser localStorage for personal journal data

## Status

The Yard is under active development.

## Privacy

Tasting journal entries are stored locally in the
visitor's browser. They are not automatically
synchronized between devices.

## Philosophy

Explore everywhere. Bring the good stuff home.
